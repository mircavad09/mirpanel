## Texniki qərarlar

- İlkin HTML, özünə canonical, bir H1, Azərbaycan dili, Product/Offer/BreadcrumbList/Organization.
- Offer qiymətləri yalnız aktiv paketlərin saxlanmış satış qiymətləridir, AZN göstərilir.
- Canlı stok təsdiqlənməyibsə InStock yazılmır. Açıq soldOut qaydası OutOfStock kimi qalır.
- Mövcud stok və qiymət server yoxlamaları, balans, sifariş və təhvil məntiqi dəyişdirilmir.
- Köhnə aktiv məhsul ünvanları 301; mövcud olmayan məhsullar 404 qalır.
- .page mənbə ünvanları və index.html əsas ünvana yönləndirilir.
- Sitemap yalnız açıq canonical ünvanları saxlayır. Faktiki tarix məlum deyilsə lastmod buraxılır.
  Məhsulun açıq məzmunu admin tərəfindən dəyişdiriləndə seoUpdatedAt yenilənir; build tarixi deyil.
- Kateqoriyalara və oxşar məhsullara, əlaqə/şərtlər və Sifarişlərimdəki Təlimata faydalı keçidlər var.
- Şəxsi hesab/səbət/balans/ödəniş və admin cavablarının noindex qaydaları qorunur.
- Uzun təkrarlanan reklam mətnləri qısa məhsul faktları ilə əvəz olunur; yeni böyük şəkil və JS kitabxanası əlavə olunmur.

## GEO və botlar

Google-un AI görünüşləri üçün ayrıca “GEO schema” tələbi yoxdur; indekslənmə və faydalı məzmun əsasdır:
https://developers.google.com/search/docs/appearance/ai-features

Product məlumatını ilkin HTML-də saxlamaq tövsiyəsi:
https://developers.google.com/search/docs/appearance/structured-data/product-snippet

OAI-SearchBot axtarış üçündür və GPTBot təlim botundan ayrıdır:
https://developers.openai.com/api/docs/bots

Canlı robots.txt Cloudflare tərəfindən əlavə olunan təlim məhdudiyyətləri daşıyır.
Googlebot, Bingbot və OAI-SearchBot üçün açıq səhifələr ümumi qaydada açıqdır.
GPTBot və Google-Extended kimi təlim qaydaları bu SEO işi üçün açılmır.
Google-Extended məhdudiyyətinin Gemini istifadəsi üçün ayrıca təsiri ola bilər; Google Search indekslənməsi ilə eyni deyil.
llms.txt və agent discovery fayllarının mövqe artımı verdiyinə dair zəmanət yoxdur; əlavə saxta “AI API” qurulmur.
Botun robots icazəsi Cloudflare təhlükəsizlik sisteminin hər sorğunu mütləq buraxacağını sübut etmir.
