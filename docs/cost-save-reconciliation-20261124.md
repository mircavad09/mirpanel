Existing report projection deducts only retained quantities for partial cancellation, and existing fee/supplier reporting is untouched. Fully cancelled/rejected/expired/unpaid orders are excluded. A second save is a no-op for repaired costs; later package changes never overwrite the captured known cost. Existing monthly archive rows are not updated. No order status, amount, wallet, stock or fulfillment write occurs.

The costs-saved event now invalidates order pages and refreshes an open order report in background with the existing automatic anchor/filter preservation. Other tabs receive a localStorage signal and check again on focus/visibility. The editor reports the number of repaired orders and precise mismatches.
